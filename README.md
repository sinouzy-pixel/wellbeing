# 🌱 Life ROI Tracker

時間とお金というコストをどれだけかけて、幸福度と成長にどれだけ寄与したかがひと目でわかる自己投資マネジメントWebアプリケーション。

## 概要
日々の活動にかける「時間（h）」と「お金（¥）」を投資リソースと捉え、それによって得られる「成長ポイント（スキル・知識）」と「幸福度ポイント（充足感・リフレッシュ）」を自動換算・可視化します。

## 主な機能
- **ワンタップ時間計測**: カードをタップするだけでタイマー開始
- **幸福度・成長ポイント換算**: 活動レート × 時間 × 充実度評価（1〜5段階）で即時ポイント化
- **Life ROI 4象限マトリクス**: 投資コスト対効果のバランスを視覚的に把握
- **分析ダッシュボード**: 日別推移グラフ、カテゴリ別配分、時間効率ランキング
- **PWA・スマホ対応**: スマートフォンのホーム画面に追加してアプリとして利用可能
- **ローカル保存**: LocalStorageによる完全プライベート・安全なデータ管理

## 使い方
1. ブラウザで `index.html` を開きます。
2. 活動カードをタップして時間を計測、または「＋ 手動記録」から入力。
3. 終了時に「費用（円）」と「実感・充実度（★）」を評価して記録完了。
